公开网站没有 MCP

yinji.modiqi.com 只提供人工在浏览器里做视觉盖章。这里没有 MCP 服务，也没有远程自动盖章接口。不要把文件打到本域名，也不要假设本站会执行任务。

若你持有一份本地印迹副本：

  1. 读仓库根目录的 agent-manifest.json，按其中 transport 在本地启动。
  2. stdio 入口是 tools/ai/yinji-mcp-server.mjs。
  3. 只做视觉盖章与扫描视觉模拟；不要把它当成数字签名服务。

操作契约、JSON Schema 与外部 sign 流程不在本页提供，只存在于本地仓库。本域名不运行 MCP，也不会自动盖章。

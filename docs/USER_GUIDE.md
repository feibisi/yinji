# 印迹用户指南

## 让自己的 AI Agent 使用

Yinji 提供 MCP 和 JSON 任务两种入口。Agent 不需要识别按钮坐标，可以直接用“末页、右下角、缩小到 18%、透明度 82%、深浅 75、去白底”这类结构化参数处理文件。

接入前把仓库绝对路径和 `agent-manifest.json` 提供给 Agent；支持 MCP 的客户端启动 `tools/ai/yinji-mcp-server.mjs`，其他客户端使用 `tools/ai/yinji-task.mjs --task <task.json>`。每次仍需由用户确认使用哪个印章及其权限，Agent 完成后必须校验证据记录。

## 1. 打开与盖章

1. 在“文件”区选择 PDF、PNG 或 JPG。
2. 选择印章图片；默认会自动清除与画布边缘连通的近白色背景，不会删除红章内部封闭的白色区域。
3. 点击“添加普通章”或“添加骑缝章”。
4. 选中已放置的章后拖动“深浅”滑块，会立即更新当前章；新添加的章也沿用该值。
5. 普通章可以拖动、缩放和删除。骑缝章会按总页数切片，并在导出前检查每页是否完整。

“去白底”按钮始终从原始印章素材重新处理，避免连续处理造成边缘越来越糊。

## 2. 印章库与隐私

普通“保存到印章库”只保存在当前浏览器会话。关闭整个浏览器后素材消失，刷新当前页面不会丢失。

需要备份时使用：

- **加密备份**：输入口令，下载 `.yinji-vault.json`；使用 PBKDF2-SHA-256 和 AES-256-GCM。
- **恢复加密备份**：选择备份文件并输入原口令；恢复会先确认，再替换当前印章库。

口令不会写入文件或浏览器存储。忘记口令无法恢复。退出共享设备前仍应清空印章库。

## 3. 批量模板

“导出 → 批量处理”支持：

- 页码：`all`、`first`、`last`、`1,3-5,last`；
- 位置：居中、四个角；
- 水平/垂直偏移：PDF 点；
- 印章宽度和不透明度：留空时沿用当前设置。

人工界面的批量结果下载为 `.yinji.zip`，内含 PDF 和同名 `.yinji.json`；图片来源的证据包内含 PNG 和侧车。

## 4. 证据记录的含义

证据记录包含源文件和输出文件的 SHA-256、页数、盖章位置、模式及生成时间。它用于核对本机产物和复现处理步骤。人工界面每次只下载一个 ZIP，不需要授予多文件自动下载权限。

它**不是**数字证书签名，不证明签署者身份，也不能阻止别人修改 PDF。需要法律或组织要求的数字签名时，使用外部签名接口并由证书管理员配置证书和时间戳服务。

## 5. 扫描件

扫描件功能只模拟纸张、噪点、倾斜、水印和元数据效果。它不代表文件真的经过扫描仪，也不会提高法律效力。导出仍会生成证据记录。

## 6. 常见问题

- **白底没去掉**：白色若没有与图片边缘连通，会被保留；可先在图像软件中清理，或提高原图对比度。
- **深浅没有变化**：先点选画布中的章，再拖动滑块。骑缝章任意一片被选中时会更新整组。
- **骑缝章不能导出**：某片被删除后会提示缺页；撤销删除或重新添加完整骑缝章。
- **下载的是 ZIP**：解压后可得到结果文件和对应 `.yinji.json`，应一起归档。

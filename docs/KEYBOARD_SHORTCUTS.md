# PDF Stamper - 键盘快捷键文档

**版本**: v1.2.0
**更新日期**: 2026-01-08

---

## 📋 所有快捷键

### 编辑操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+Z` / `Cmd+Z` | 撤销 | 撤销上一步操作 |
| `Ctrl+Y` / `Cmd+Y` | 重做 | 重做已撤销的操作 |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | 重做 | 重做已撤销的操作（备选） |
| `Delete` | 删除 | 删除选中的印章 |
| `Backspace` | 删除 | 删除选中的印章（备选） |
| `Esc` | 取消选择 | 取消当前选中的印章 |

### 移动操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` | 向上移动 | 将选中印章向上移动 1px |
| `↓` | 向下移动 | 将选中印章向下移动 1px |
| `←` | 向左移动 | 将选中印章向左移动 1px |
| `→` | 向右移动 | 将选中印章向右移动 1px |
| `Shift+↑` | 快速向上 | 将选中印章向上移动 10px |
| `Shift+↓` | 快速向下 | 将选中印章向下移动 10px |
| `Shift+←` | 快速向左 | 将选中印章向左移动 10px |
| `Shift+→` | 快速向右 | 将选中印章向右移动 10px |

### 视图控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `+` / `=` | 放大 | 增加页面缩放 (10%) |
| `-` / `_` | 缩小 | 减少页面缩放 (10%) |
| `PageUp` | 上一页 | 切换到上一页 |
| `PageDown` | 下一页 | 切换到下一页 |

### 文件操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+S` / `Cmd+S` | 导出PDF | 导出盖章后的PDF文件 |

### 帮助

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `?` / `Shift+/` | 显示帮助 | 显示键盘快捷键帮助面板 |

## 💡 使用技巧

### 精确定位印章
1. 使用鼠标拖动印章到大致位置
2. 选中印章后使用方向键微调位置
3. 按住 `Shift` 使用方向键快速移动

### 快速工作流
1. `Ctrl+S` 快速导出，无需点击按钮
2. `PageUp/PageDown` 快速浏览多页文档
3. `+/-` 调整缩放查看细节

### 撤销/重做
- 支持最多 50 步历史记录
- 所有操作都可撤销：添加、删除、移动印章
- 使用 `Ctrl+Z` 撤销，`Ctrl+Y` 重做

---

## 🎯 快捷键设计原则

1. **跨平台兼容**: 支持 Windows (`Ctrl`) 和 macOS (`Cmd`)
2. **标准化**: 遵循常见应用的快捷键习惯
3. **无冲突**: 避免与浏览器默认快捷键冲突
4. **易记**: 使用直观的按键组合

---

## 🔧 自定义快捷键

当前版本不支持自定义快捷键。如需自定义，请修改 `src/main.js` 中的键盘事件处理代码。
